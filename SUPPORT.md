# Support

Thanks for using Web Pulse Analytics. Here is where to get help.

## I found a bug

Open a **bug report** using the
[issue form](https://github.com/heyshreee/Web-Pulse-Analytics/issues/new?template=bug_report.yml).
Please include reproduction steps, expected vs. actual behavior, and your environment.
Redact secrets and any real visitor data from logs and screenshots.

## I want a feature

Open a **feature request** with the
[issue form](https://github.com/heyshreee/Web-Pulse-Analytics/issues/new?template=feature_request.yml).
Note whether it targets the stable line (`v1-stabilization`) or new UI work (`v2-ui`).

## I have a question about using the product

- Read the docs in [`docs/`](docs/), starting with
  [getting-started.md](docs/getting-started.md) and
  [tracking-guide.md](docs/tracking-guide.md).
- For setup and contribution questions, see [CONTRIBUTING.md](CONTRIBUTING.md).
- If your question is not answered there, open a
  [discussion or issue](https://github.com/heyshreee/Web-Pulse-Analytics/issues) with
  the `question` label.

## I found a security vulnerability

**Do not** post it publicly. Follow the private process in
[SECURITY.md](SECURITY.md).

## I want to contribute

Start with [CONTRIBUTING.md](CONTRIBUTING.md). Look for issues labeled
`good first issue` or `help wanted`.

## Response expectations

This is a small, early-stage project maintained on a best-effort basis. Security
reports are prioritized (see [SECURITY.md](SECURITY.md)); other requests are
triaged as time allows. Clear, well-scoped reports are resolved fastest.

## Contact

The project is maintained by [`@heyshreee`](https://github.com/heyshreee). For
anything that should not be public, use the private channels above.
